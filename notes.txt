


Consider storing terminfo.src (with comments removed and the source compacted using xz -9, reducing it to about 85 KB) instead of keeping the entire compiled terminfo database. A startup script could then compile only the desired terminal descriptions.

The list of terminal types to compile could be specified through a configuration variable or a separate file, such as /etc/terminfo_list.cfg.


File /etc/terminfo.cfg
TERMLIST='linux,xterm,xterm-256color,screen,screen-256color,tmux,tmux-256color,vt100' \


File /etc/rc.d/init.d/terminfo_setup
. /etc/terminfo.cfg
xz -dk /usr/share/terminfo/terminfo.src.xz
tic -x -o /usr/share/terminfo -e '$TERMLIST` /usr/share/terminfo/terminfo.src.xz
rm /usr/share/terminfo/terminfo.src
